# v0.1.0-alpha.2

Direct-connect lobby prototype for Minecraft 26.2 / Fabric Loader 0.19.3.

- custom Evgenium SpeedRun menu;
- create a lobby on a user-selected TCP port;
- join a lobby by IP:port;
- synchronized lobby player list;
- return from the speedrun menu to the vanilla title screen;
- open the speedrun lobby selector from the vanilla title screen;
- Minecraft 26.2 Gui API compatibility.

The race start button is intentionally disabled in this build. This release is for end-to-end lobby networking and UI testing.
