# Evgenium SpeedRun

Evgenium SpeedRun is a Fabric-based competitive Minecraft speedrunning client/mod.

## Target stack

- Minecraft Java Edition: **26.2**
- Fabric Loader: **0.19.3**
- Fabric API: **0.156.0+26.2**
- Fabric Loom: **1.17-SNAPSHOT**
- Java: **25**
- Gradle: **9.5.1**

## Project direction

The project is intended to become a dedicated speedrun platform rather than a conventional content mod. Planned core systems include:

- a fully custom main menu;
- human-friendly multiplayer lobbies;
- ready-state and synchronized match starts;
- identical or controlled world seeds per match;
- isolated local worlds for each runner;
- built-in timers and finish detection;
- later: seed filtering, controlled RNG, matchmaking, ratings, spectating and replays.

## Current status

Initial project foundation is being built.
